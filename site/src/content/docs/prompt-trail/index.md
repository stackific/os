Each step of building Stackific OS is one task, one pull request and one entry here. An entry holds the task's expectations, the prompt that built it, what came out, and each review round.

The expectations are the test. AI models drift, so the same prompt on a newer model may produce a different result. That is acceptable: a rebuild that meets the expectations is valid.

Entries for work on both bases sit at the top of the trail. Work on one base sits under **Arch** or **Fedora**.
